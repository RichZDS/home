刚进大学时，大家都要四处收集资料：作业答案、PTA 代码和思路、历年试卷、学长学姐做的 A4 纸，还有上完一门课才恍然大悟的技巧。有的资料一找就有，有的要费很大力气，很多时候能不能拿到全凭运气。

[SDUT](https://github.com/RichZDS/SDUT) 这个仓库想解决的就是这件事。README 里写道：

> 我为这一年一年，这么多人孤军奋战的重复劳动感到不平。

> 我希望只要是前人走过的弯路，后人就不必再走。

这段前言借鉴了浙大学习指南 [zju-icicles](https://qsctech.github.io/zju-icicles/)，README 里也注明了出处。

## 仓库怎么组织

按学期分目录，每门课一个 README，资料和经验放在一起：

```text
SDUT/
├─ 大一下/
│  └─ README.md          # 本学期科目总览
└─ 大二上/
   ├─ 离散数学/          # 经验 + 思维导图
   ├─ 线性代数（B）/
   ├─ 面向对象/          # 经验 + 往年试卷
   ├─ 马克思主义原理/
   └─ 操作系统.rar
```

仓库在 GitHub 上收到了 3 个 star，数字不大，但对一个面向单个专业的资料库来说，说明真的有人在用。

## 各门课的经验

下面是从各门课 README 里整理出来的建议。

### 大一下

- **计算机组成原理**：408 考研科目之一。学的范围比普通计科窄，难点在英语。实验课前期不难，后面几次会变难，要把实验和课本对照着学。
- **程序设计基础**：上学期的进阶，从结构体一路讲到贪心和动态规划，难度直线上升。题目基本和 PTA 相关，**多刷 PTA** 是最直接的办法。
- **高级程序设计**：全英文授课，学 Java。期末要做一个小游戏（比如纸牌游戏）并答辩。
- **计算机科学基础**：全英文授课，是下学期离散数学的基础。

### 大二上

- **离散数学**：这学期难度最高。以定义和性质定理为主，是后面数据结构的基础。刚开始听不懂很正常，回头再看会突然开窍。老师上课强调的往年题一定要标出来，期末前讲解的那套旧卷要吃透。另外它和四六级、操作系统的考试挨得很近，要提前安排复习。
- **面向对象**：整体偏难，挂科率不低。建议提前在网上找 Java 基础课补一补，再突击背一下英文术语。
- **线性代数（B）**：老师会把笔记整理在语雀上，照着学就行。

## 为什么这种仓库值得做

1. **信息差是能消除的**。一门课的重点、考试形式、容易踩的坑，写下来只要十几分钟，却能省下后来人好几周的摸索。
2. **仓库比群聊可靠**。群文件会过期，聊天记录会被刷走，Git 仓库有目录、有历史，还能接受别人的 PR。
3. **写下来也是复盘**。给别人写经验的时候，会重新想一遍这门课到底在讲什么。

README 里也写了：如果有文件侵犯了谁的权益，可以联系作者删除。分享资料的同时尊重版权，这一条不能少。
